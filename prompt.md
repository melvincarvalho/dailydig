# The prompt

This repository is an experiment in prompt-driven commercial game
development: a bigger scope than the one-shot tributes, built deliberately as
a foundation plus a long campaign of harsh critical passes. This is the
prompt that produced it.

```
Build DAILY DIG: a commercial daily-speedrun mining puzzle for the open web.
One provably-fair cave for the whole world every day. Dig the quota, reach
the exit, race the Foreman — a deterministic solver whose clear both proves
the day is beatable and provides the ghost everyone races. Finishing yields
a Wordle-class share: an emoji strata grid plus a link that IS your replay —
anyone who opens it races your ghost. No accounts, no server, no install:
GitHub Pages, localStorage streaks, replays in the URL, Nostr for the
global board later.

Everything from code, zero assets. The simulation is a pure importable core
(daily seed rule, cave generation, tick physics, solver, replay codec) with
machine-verified proofs, a mutant gate, and a 60-day solvability contract
run on every change. Replays are the anti-cheat: a time claim is a tape,
and every client can verify a tape.

Ship the foundation plain, then run a large number of critical passes —
feel, generation, art, animation, sound, onboarding, share, ghosts, meta,
mobile, network, performance, fairness, accessibility — each one evidenced
by deterministic screenshots and strips, graded against a commercial bar,
and landed as an issue + PR with the full harness green.
```
